# Application Development Workflow Skill

This folder contains a reusable `SKILL.md` for AI coding agents such as Codex-style agents.

## Installation

Copy the `application-development-workflow` folder into your agent's personal skills directory.

Expected structure:

```text
skills/
└── application-development-workflow/
    └── SKILL.md
```

## Example triggers

- “Convert my hospital management idea into an application plan.”
- “Define roles and workflow for creating a SaaS application.”
- “Create an MVP roadmap for my URL shortener.”
- “Explain the complete software development work cycle.”
